⚠️ IMPORTANTE: Escopo de Fornecimento - Sistema de Fila Virtual

O que está INCLUÍDO nesta proposta:

  • ✅ Software completo do sistema de fila virtual (emissão de senhas, painel, chamadas)
  • ✅ Interface web responsiva para exibição em qualquer TV/monitor conectado à internet
  • ✅ Sistema de chamada integrado ao consultório do médico/dentista
  • ✅ Métricas e relatórios de tempo de espera e fluxo de pacientes

O que NÃO está incluído:

  • ❌ Totem físico (hardware) para emissão de senhas — cliente pode usar tablets, computadores ou contratar totem separadamente
  • ❌ TVs/monitores para exibição — cliente utiliza equipamentos próprios
  • ❌ Token físico NFC/RFID para controle preciso de tempo de atendimento

Alternativa econômica: O cliente pode usar tablets ou computadores próprios com navegador web para emissão de senhas, eliminando necessidade de totem dedicado.

📋 Requisito: Certificado Digital para Receitas Digitais

Receitas médicas e odontológicas digitais com validade jurídica exigem assinatura com Certificado Digital ICP-Brasil (padrão A1 ou A3) de cada profissional emissor, conforme regulamentação CFM/CFO.

  • O certificado é de responsabilidade de cada médico/dentista — não é fornecido nem custeado pelo sistema.
  • Custo aproximado: R$ 150–350/ano por profissional, emitido por certificadoras credenciadas (Serasa, Valid, Soluti, entre outras).
  • O sistema integra a assinatura automaticamente após o profissional instalar o certificado no dispositivo.
  • Sem certificado: receitas geradas em PDF sem assinatura digital (disponíveis apenas para impressão).

Tipos de Relatórios

Relatórios SINTÉTICOS (Visão Executiva)

Fornecem visão consolidada e resumida, ideal para gestores e coordenadores tomarem decisões rápidas:

  • Total de consultas por unidade (mensal/anual)
  • Taxa de ocupação das agendas (% de aproveitamento)
  • Indicadores de faltas e cancelamentos (% geral)
  • Resumo financeiro (faturamento x despesas por unidade)
  • Horas trabalhadas consolidadas por profissional (para folha)
  • Produtividade por especialidade (pacientes/hora)
Relatórios ANALÍTICOS (Visão Detalhada)

Fornecem detalhamento granular com todas as linhas de dados, ideal para auditoria, análise profunda e investigação:

  • Lista completa de consultas (paciente, data, hora, profissional, status, procedimentos)
  • Detalhamento de faltas (quem faltou, quando, justificativa, histórico de recorrência)
  • Relatório de procedimentos realizados (código TUSS, valor, autorização, lote)
  • Horas detalhadas por profissional (agenda por agenda, dia/hora, valor unitário)
  • Movimentação financeira linha a linha (contas, notas fiscais, pagamentos)
  • Auditoria de ações (quem fez o quê, quando, log completo)

⚠️ Relatório de Tempo de Atendimento — Precisão Limitada sem Hardware

O relatório de tempo por consulta tem precisão variável conforme a disponibilidade de hardware dedicado:

  • Com token de atendimento (NFC/RFID): precisão exata — médico aciona o dispositivo ao iniciar e encerrar cada consulta.
  • Sem hardware (padrão desta proposta): tempo estimado via eventos do sistema (abertura e fechamento do prontuário).
  • O token de atendimento não está incluído nesta proposta e pode ser cotado separadamente como escopo futuro.

Por que Azure Cloud?

Vantagens Técnicas

  • Escalabilidade automática — cresce conforme demanda
  • Backup diário automatizado — dados sempre protegidos

Segurança e Compliance

  • Conformidade LGPD e ISO 27001
  • Criptografia de dados em repouso e trânsito

  • Auditoria de acesso e logs completos

Componentes de Infraestrutura

Azure App Service

Hospedagem da aplicação web (frontend e backend)

Azure SQL Database

Banco de dados relacional gerenciado

  • Backup automático diário

Azure Blob Storage

Armazenamento de arquivos (fotos, raio-X, documentos)

Controle e Governança

Rastreabilidade Total e Prevenção de Erros

Saiba quem fez o quê, quando e por quê. Previna erros antes que aconteçam.

Auditoria Completa

  • Quem abriu/fechou agendas

    Rastreie qual coordenador liberou horários, quando e para qual profissional

  • Quem agendou/cancelou consultas

    Histórico completo de mudanças com usuário, data/hora e motivo

  • Alterações em fichas clínicas

    Versionamento: veja o que mudou, quem alterou e quando

  • Acessos a dados sensíveis

    Conformidade LGPD: registro de quem visualizou cada prontuário

Alertas Inteligentes

  • Vencimento de documentos

    Alerta automático: CRO vencido, contratos expirando, certificados

  • Agendas com problemas

    Sistema avisa: agenda sem consultas, horários vazios, overbooking

  • Folha de pagamento inconsistente

    Detecta erros antes de processar: horas fora do padrão, valores duplicados

  • Anomalias operacionais

    Taxa de faltas anormal, tempo de fila acima do normal, etc.

Prevenção Ativa de Erros

  • Validações em tempo real

    Sistema bloqueia: agendamento duplicado, CPF inválido, dados obrigatórios faltando

  • Confirmações críticas

    Pede confirmação antes de: cancelar consulta, deletar dados, processar pagamento

  • Cálculos automáticos

    Zero erro humano: folha, CNAB, relatórios calculados pelo sistema

  • Backup automático

    Impossível perder dados: backup diário automático no Azure

Compliance Legal

  • LGPD nativo

    Consentimento, anonimização, direito ao esquecimento, relatório de acessos

  • Retenção de prontuários

    Mínimo 20 anos (CFO), armazenamento ilimitado no Azure

  • Atestados com QR Code

    Preparado para lei futura de validação digital de atestados médicos

  • Logs imutáveis

    Evidências para auditoria: ninguém pode alterar histórico de ações

Zero Tolerância a Erros = Operação Confiável

Com rastreabilidade total e alertas preventivos, você elimina 95% dos erros operacionais e garante conformidade legal total.
